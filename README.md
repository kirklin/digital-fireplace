# 数字壁炉 (Digital Fireplace)

一个互动网页应用，让用户可以将文件拖入火焰中，伴随着壁炉火燃烧的噼啪声，给人一种仪式感和解压体验。

## 功能特点

- 🔥 逼真的火焰效果，带有动画和粒子效果
- 🔊 舒缓的壁炉火燃烧白噪音
- 📁 支持拖拽任何文件到火焰中"燃烧"
- ✨ 有趣的文件燃烧动画效果
- 🌙 默认黑暗主题，给人沉浸式体验

## 技术栈

- Next.js 15
- React 19
- TailwindCSS 4
- React-Dropzone

## 使用方法

1. 克隆仓库
2. 安装依赖：`pnpm install`
3. 开发模式运行：`pnpm dev`
4. 构建项目：`pnpm build`

## 寓意

在信息爆炸的时代，有时我们需要一种仪式感来告别数字垃圾。这个数字壁炉提供了一种视觉上和听觉上的满足，帮助用户在删除文件时获得一种完成感和释放感。

将那些不再需要的文件、照片或文档拖入火焰，看着它们"燃烧"，伴随着舒缓的噼啪声，给人一种治愈和放松的感觉。
